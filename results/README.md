# Results Directory

This directory contains key outputs generated by the notebooks and scripts. It is
organized by analysis stage and file type.

## Structure

```text
results/
  eda/
    figures/              # selected EDA figures used to support design choices
    tables/               # optional EDA summary tables

  features/
    tables/               # kept / dropped / engineered feature-decision tables

  burden_analysis/
    figures/              # DS_z maps and top-zone burden figures
    tables/               # DS_z rankings and burden heterogeneity tables

  modeling/
    figures/              # model and diagnostic figures
    tables/               # Model 1/2/3 estimates and diagnostics

  final/
    figures/              # the figures shown in the presentation
    tables/               # the KPI tables behind the presentation's headline numbers
```

## How To Read These Outputs

- `eda/` supports data understanding and design choices.
- `features/` records feature-selection and feature-engineering decisions in table form.
- `burden_analysis/` answers where the fixed fee is largest relative to trip cost.
- `modeling/` reports volume-association, DiD, placebo, and diagnostic outputs.
- `final/` collects the figures and KPI tables used in the presentation, regenerated by
  [`../notebooks/final_results.ipynb`](../notebooks/final_results.ipynb).

Narrative interpretation lives in the corresponding documents under `docs/`, especially
[`../docs/eda_summary.md`](../docs/eda_summary.md),
[`../docs/burden_analysis_and_modeling_results.md`](../docs/burden_analysis_and_modeling_results.md),
and [`../docs/causal_interpretation_limitations.md`](../docs/causal_interpretation_limitations.md).
