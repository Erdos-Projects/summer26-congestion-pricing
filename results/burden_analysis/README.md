# Burden Analysis Outputs

This folder contains `DS_z` burden-ranking outputs and burden heterogeneity summaries.

- `tables/`: top zone-side rankings, pickup/dropoff rankings, burden by geography, burden by trip
  length, and airport versus non-airport burden summaries.
- `figures/`: burden maps and top-zone figures.

The main interpretation is summarized in
[`../../docs/burden_analysis_and_modeling_results.md`](../../docs/burden_analysis_and_modeling_results.md).
