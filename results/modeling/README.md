# Modeling Outputs

This folder contains Model 1, Model 2, and Model 3 result tables and diagnostic outputs.

- `tables/`: correlations, quartiles, control specifications, DiD estimates, placebo checks, and
  Model 3 diagnostics.
- `figures/`: Model 1 burden-volume plots, Model 2 exposure and placebo diagnostics, and Model 3
  cross-vehicle trend figures. The HVFHV Model 1 scatter is also available as an interactive HTML
  chart.

Files follow `<service>_model<number>_<content>` for service-specific outputs. Cross-service Model 3
files use `cross_vehicle_model3_<content>`.

The narrative interpretation is in
[`../../docs/burden_analysis_and_modeling_results.md`](../../docs/burden_analysis_and_modeling_results.md),
with detailed causal limits in
[`../../docs/causal_interpretation_limitations.md`](../../docs/causal_interpretation_limitations.md).
